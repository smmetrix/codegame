Как запустить — всего три действия

  1. Скачай ZIP красной кнопкой выше. Затем открой папку «Загрузки».
  2. Нажми на zero_day_game.zip правой кнопкой и выбери «Извлечь всё». Обязательно запускай файлы из распакованной папки.
  3. Дважды нажми START_GAME.bat. Он сам проверит Python, автоматически установит Pygame и запустит ZERO DAY. При первом запуске установка может занять 1–3 минуты.

Если Python ещё не установлен, START_GAME.bat покажет понятное сообщение и не закроется. Скачай Python 3.10+ с python.org и обязательно включи “Add Python to PATH”.

FAQ // диагностика

Не запускается?

Запускай не zero_day.py, а START_GAME.bat из распакованной папки. Он оставит окно открытым и покажет понятную ошибку.

Получился файл zero_day.py.txt?

Переименуй его в zero_day.py. При сохранении в Блокноте обязательно выбери тип «Все файлы (*.*)», иначе Windows незаметно добавит расширение .txt.

Чёрный экран?

Закрой его и запусти START_GAME.bat. Он автоматически установит совместимые pygame-ce и pygame_gui, а при ошибке не даст окну исчезнуть.

Команда pip не найдена?

Переустанови Python с включённой галочкой “Add Python to PATH” или используй python -m pip install pygame pygame_gui.

Окно сразу закрывается?

Открой папку с игрой в командной строке и выполни python zero_day.py — текст ошибки останется на экране и подскажет причину.

Нет звука?

Игра продолжит работать в бесшумном режиме, если аудиоустройство недоступно. Звуки и эмбиент также независимо переключаются в настройках.

Где хранятся сохранения?

Рядом с zero_day.py: основной save.json и нумерованные слоты save1.json, save2.json и далее.
