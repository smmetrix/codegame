# GreyHat: Python Cyberdeck

Полноценная офлайн-игра по изучению Python в интерфейсе Cyberdeck OS. Игрок проходит путь от первой переменной и `print()` до циклов, словарей, функций, шифрования, потоков и комплексных виртуальных эксплойтов.

## Возможности

- масштабируемый Cyberpunk Dark UI на CustomTkinter;
- полноэкранная инициализация оператора с пятью адаптивными профилями навыка;
- 15 последовательных сюжетных миссий в пяти уровнях сложности;
- редактор Python с line numbers, подсветкой синтаксиса и горячими клавишами;
- интерактивный терминал с цветными каналами и эффектом печатающей машинки;
- отдельный ограниченный процесс для каждого запуска пользовательского кода;
- AST-фильтрация, тайм-аут, лимиты памяти и консольного вывода;
- безопасные офлайн-симуляторы `ping()`, `scan_ports()`, `send_payload()` и `decrypt_caesar()`;
- BTC, EXP, шесть рангов, инвентарь, карма и разные финалы;
- DarkNet-магазин с четырьмя функциональными улучшениями;
- мини-игра на реакцию «Обход камер наблюдения»;
- диалоговая мини-игра «Социальная инженерия»;
- пять достижений с дополнительными наградами;
- автоматическое сохранение полного прогресса в `savegame.json`.

## Установка и запуск

Требуется Python 3.11 или новее с поддержкой Tk.

```bash
python -m pip install -r requirements.txt
python main.py
```

На Windows вместо `python` можно использовать команду `py`:

```bat
py -m pip install -r requirements.txt
py main.py
```

На Linux пакет Tk иногда устанавливается отдельно через пакетный менеджер системы, например `python3-tk`.

## Профиль навыка

Если `savegame.json` еще не существует, перед Cyberdeck открывается полноэкранная инициализация оператора. Выбранный профиль сохраняется и при следующих запусках игра сразу открывает основной интерфейс.

| Профиль | Адаптация кампании |
| --- | --- |
| Нулевой | Все 15 миссий открыты, таймеры ×3, подробное обучение, автоматические бесплатные подсказки и комментарии к каждой строке. |
| Новичок | Первые три миссии упрощены, таймеры ×2, подсказки бесплатны по запросу. |
| Практик | Стандартные миссии и таймеры, краткие учебники, подсказка стоит 10 BTC. |
| Продвинутый | Учебники скрыты, таймеры ×0.7, подсказка стоит 30 BTC, Firewall адаптивно повышает Trace. |
| Senior | Таймеры ×0.4, подсказки отключены, добавлены ложные данные, секретные цели и проверка очевидных решений O(n²). |

## Управление

- `F5` или `Ctrl+Enter` — выполнить код текущей миссии;
- `Ctrl+S` — сохранить прогресс;
- `Ctrl+/` — добавить или убрать комментарий;
- `Tab` / `Shift+Tab` — изменить отступ;
- `HINT` — открыть подсказку;
- `CPU STEP` — применить купленное улучшение Overclocked CPU;
- `DARKNET` — открыть магазин;
- `MINI-GAMES` — открыть тренировочные симуляции;
- `ACHIEVEMENTS` — посмотреть достижения.

Локальный терминал поддерживает команды:

```text
help
status
missions
mission <1-15>
run
hint
reset
trace
scan <host>
shop
overclock
minigames
achievements
save
clear
```

## Модель безопасности

Пользовательский код не исполняется в GUI-процессе. Перед запуском он проверяется через AST, после чего выполняется в отдельном процессе с урезанными builtins, разрешенным списком безопасных модулей, лимитом времени, памяти и вывода. Реальные файловые, сетевые и процессные API внутри учебной песочницы недоступны.

BruteForce Toolkit добавляет только ограниченные офлайн-функции. Он не открывает доступ к сети или файловой системе.

Как и любая песочница уровня языка, этот механизм предназначен для локальных учебных сценариев игры, а не для исполнения кода от недоверенных удаленных пользователей на публичном сервере.

Файл `greyhat_cyberdeck.py` сохранен как ранняя автономная сборка-прототип. Актуальная модульная версия запускается командой `python main.py`.
