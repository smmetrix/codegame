# GreyHat: Python Cyberdeck

Полноценная офлайн-игра по изучению Python в интерфейсе Cyberdeck OS. Игрок проходит путь от первой переменной и `print()` до циклов, словарей, JSON-парсинга, шифра Цезаря и брутфорса.

Весь запускаемый проект собран в одном автономном файле **`greyhat_cyberdeck.py`**. Файл содержит GUI, кампанию, состояние игрока и изолированный движок выполнения кода.

## Возможности

- современный Cyberpunk Dark UI на CustomTkinter;
- 10 последовательных обучающих миссий;
- редактор реального Python-кода и встроенный терминал;
- отдельный процесс для каждого запуска кода;
- AST-фильтрация опасных конструкций и модулей;
- ограничения времени, памяти и размера вывода;
- безопасные симуляторы `ping()`, `scan_ports()`, `send_payload()` и `decrypt_caesar()`;
- перехват `stdout`, `stderr`, результата и созданных переменных;
- BTC, EXP, шесть рангов, инвентарь и магазин DarkNet;
- три пути кармы и разные финалы;
- автоматическое локальное сохранение прогресса.

## Запуск

Требуется Python 3.11 или новее с поддержкой Tk.

```bash
python -m pip install -r requirements.txt
python greyhat_cyberdeck.py
```

На Linux пакет Tk может устанавливаться отдельно через пакетный менеджер системы, например `python3-tk`.

Сохранение создается вне репозитория:

```text
~/.greyhat_cyberdeck/greyhat_save.json
```

## Управление

- `F5` — выполнить код текущей миссии;
- `Ctrl+S` — сохранить прогресс;
- `RUN CODE` — выполнить код в песочнице;
- `HINT` — показать подсказку;
- `DARKNET` — купить улучшения;
- `INVENTORY` — открыть инвентарь.

Локальный терминал поддерживает команды:

```text
help
status
missions
mission <01-10>
run
hint
scan <host>
inventory
darknet
save
clear
```

## Модель безопасности

Пользовательский код не исполняется в GUI-процессе. Перед запуском он проверяется через AST, после чего выполняется в отдельном процессе с урезанными builtins, разрешенным списком безопасных модулей, лимитом времени, памяти и вывода. Реальные файловые, сетевые и процессные API внутри учебной песочницы недоступны.

Как и любая песочница уровня языка, этот механизм предназначен для локальных учебных сценариев игры, а не для запуска кода от недоверенных удаленных пользователей на публичном сервере.
